# Task 10 Evidence: /metrics endpoint

## Changes Made

### `src/http/routes.ts`
- Added module-level `metricsStore` (Map<string, number>) singleton
- Added `incrementMetric(name, labels)` export for tracking counters
- Added `handleMetricsRoute` that outputs Prometheus text exposition format
  - Content-Type: `text/plain; version=0.0.4; charset=utf-8`
  - Includes `# HELP` and `# TYPE` headers for `mcp_requests_total`

### `src/http/request-handler.ts`
- Imported `handleMetricsRoute` and `incrementMetric` from routes
- Wired `/metrics` path in the routing chain (after `/health`)
- `/metrics` already exempt from rate limiting (was in exemptPaths from prior task)
- Added `incrementMetric` calls for `/mcp`, `/sse`, `/messages` routes with `{tool, status}` labels
- Added error-path metric increment in catch block

## Prometheus Output Format
```
# HELP mcp_requests_total Total number of MCP requests
# TYPE mcp_requests_total counter
mcp_requests_total{tool="mcp",status="attempt"} 1
mcp_requests_total{tool="mcp",status="success"} 1
```
